How I work

Clean architecture
Maintainable C# built on SOLID principles and patterns like MVC, State, and Observer. Addressables, save systems, and resource loading designed to scale as a game grows.
Performance
Fewer ANRs (down 35% on one project), builds up to 50% smaller, and steady frame rates through memory management, GC tuning, batching, and animation baking.
Monetization and LiveOps
Ad mediation, analytics, level systems, remote configs, and A/B tests, so a game can be tuned after launch.
Fast prototyping
Prototypes for publishers including TapNation, Supersonic, Voodoo, Zplay, and Casual Azur.
